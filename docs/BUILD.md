# Build and deployment

Requirements: Node 20 or later (developed on Node 24) and npm. Android builds need Android Studio with JDK 17 or later. iOS builds need a Mac with Xcode 16 or later.

```bash
npm install
```

---

## Web

### Development

```bash
npm run dev
```

The service worker only registers in production builds, so dev reloads stay fresh.

### Production build

```bash
npm run build
```

This runs `next build` (static export to `out/`), then `scripts/postbuild-sw.mjs`, which writes the list of every exported file into `out/sw.js` so the installed app works fully offline.

Preview it locally:

```bash
npx serve out
```

### Deploy

`out/` is plain static files. Upload it to any static host: Netlify, Vercel (static), Cloudflare Pages, GitHub Pages, S3 + CloudFront, or nginx.

- Serve over **HTTPS**. Service workers and notifications require it.
- Serve `sw.js` with `Cache-Control: no-cache` so updates are picked up.
- Routes use trailing slashes (`/calendar/` → `calendar/index.html`). Most static hosts handle this without configuration.

### PWA installation

- **Chrome / Edge (desktop and Android):** the install icon in the address bar, or ⋮ → *Install BirthdayBook*.
- **Safari on iPhone:** Share → *Add to Home Screen*. Web notifications on iOS need 16.4 or later and only work from the home-screen app.

Regenerate icons after changing the brand mark:

```bash
npm run icons
```

## Android

The `android/` folder is a standard Gradle project generated by Capacitor 8 (compileSdk 36, targetSdk 36, minSdk 24).

### One-time setup

1. Install [Android Studio](https://developer.android.com/studio). It includes the SDK and a JDK.
2. Set `ANDROID_HOME`, or let Android Studio create `android/local.properties` on first open.

### Build web assets into the native project

```bash
npm run cap:sync        # npm run build && npx cap sync
```

Run this after every web change.

### Open in Android Studio

```bash
npm run android         # build + sync + open Android Studio
```

Then press **Run** with a device or emulator selected.

### What's already configured

`android/app/src/main/AndroidManifest.xml`:

| Permission | Why |
|---|---|
| `POST_NOTIFICATIONS` | Android 13+ runtime notification permission. Requested from the dashboard or Alarm Centre, never on launch |
| `RECEIVE_BOOT_COMPLETED`, `WAKE_LOCK` | The Local Notifications plugin re-registers alarms after a reboot |
| `VIBRATE` | Vibration on reminder channels |
| `SCHEDULE_EXACT_ALARM` | Declared but only requested when the user turns on *Precise timing*. `USE_EXACT_ALARM` is deliberately not used; Google Play restricts it to alarm-clock and calendar apps |

Also configured:

- `allowBackup="false"`: no silent Google Drive backup; data leaves the device only through exports.
- Notification channels are created at runtime (`platform/android/channels.ts`): *Upcoming celebration reminders* (high), *Celebration day* (max), *Snoozed reminders*. Each has sound and silent variants, because Android freezes a channel's sound once it exists.
- `res/drawable/ic_stat_birthdaybook.xml`: monochrome status-bar icon.
- `res/raw/silence.wav`: used by the silent channel variants.
- Launcher icons and splash screens come from `resources/` via `npx @capacitor/assets generate`.

### Debug APK

```bash
npm run android:debug
```

On Windows, if `gradlew` isn't found from npm, run it from the folder:

```bash
cd android && ./gradlew assembleDebug
```

Output: `android/app/build/outputs/apk/debug/app-debug.apk`. Install it with `adb install -r app-debug.apk`.

### Release APK / AAB

1. Create an upload key once. Keep it safe and out of git:

   ```bash
   keytool -genkeypair -v -keystore birthdaybook-upload.jks -alias birthdaybook -keyalg RSA -keysize 2048 -validity 10000
   ```

2. Create `android/keystore.properties` (git-ignored):

   ```properties
   storeFile=../birthdaybook-upload.jks
   storePassword=…
   keyAlias=birthdaybook
   keyPassword=…
   ```

3. Bump `versionCode` and `versionName` in `android/app/build.gradle`.

4. Build:

   ```bash
   npm run android:release                      # AAB for Google Play
   ```

   ```bash
   cd android && ./gradlew assembleRelease      # signed APK for sideloading
   ```

   Outputs go to `android/app/build/outputs/bundle/release/app-release.aab` and `android/app/build/outputs/apk/release/app-release.apk`.

5. Upload the AAB in Play Console. In the *App content → Data safety* form, you can declare that no data is collected or shared.

## iOS

The `ios/` folder is an Xcode project using Swift Package Manager (Capacitor 8 default), so CocoaPods isn't needed.

### Build and open

```bash
npm run ios            # build + sync + open Xcode (macOS only)
```

### Xcode configuration

1. Select the **App** target → *Signing & Capabilities* → choose your Team. Change the bundle identifier from `com.birthdaybook.app` if it's taken.
2. No extra capability is needed for local notifications. Push Notifications and Background Modes are **not** required.
3. `Info.plist` already includes:
   - `UIFileSharingEnabled` + `LSSupportsOpeningDocumentsInPlace`, so exports saved to *Documents/BirthdayBook* appear in the Files app under *On My iPhone → BirthdayBook*.
   - `ITSAppUsesNonExemptEncryption = NO`.
4. The notification permission prompt appears when the user taps *Allow notifications*. iOS lets the app ask only once; after a denial the Alarm Centre sends the user to Settings.

### Device testing

1. Connect an iPhone, trust the Mac, and enable *Developer Mode* (Settings → Privacy & Security).
2. Pick the device in Xcode and press **Run**.
3. Notifications don't fire reliably in the Simulator while the app is killed. Test that on a real device (see `docs/TESTING.md`).

### Archive and release

1. Set *Version* and *Build* on the App target.
2. Choose **Any iOS Device (arm64)** → *Product → Archive*.
3. In the Organizer: *Distribute App → App Store Connect → Upload*.
4. Test via TestFlight, then submit for review. For the privacy nutrition label, declare *Data Not Collected*.

## Updating Capacitor plugins

```bash
npm install @capacitor/core@latest @capacitor/cli@latest @capacitor/android@latest @capacitor/ios@latest @capacitor/local-notifications@latest
```

```bash
npx cap sync
```

After updating `@capacitor/local-notifications`, re-check `platform/native/local-notifications.ts`, especially the `isExactNotification` handling.
